# 🔍 鑑識現場 Forensic Scene Online

《Phasmophobia》式的合作鑑識遊戲：1–4 名鑑識人員開著**行動鑑識車**抵達命案別墅，帶對工具、花對行動點數，在時間壓力下找出**行兇方式、兇器、第一現場與兇手**，最後提交推理報告評分。斜 45° 俯視（類 Among Us）2D，桌機與 iPhone 都能玩。

- 單人（離線也能玩）：<https://190boy.github.io/forensic-scene-online/>
- 多人連線需要部署伺服器（Render 免費方案，見下方）。

## 怎麼玩
1. 首頁輸入名字、選隊員與難度 → 「單人調查」或「建立房間」（4 位數房號，把邀請連結傳給隊友）。
2. 在鑑識車選最多 3 件攜帶工具（第一次免費，之後每次更換 -1 點），走進封鎖線，靠近發亮的「!」物件，點按鈕採證（每個動作各自扣點）。
3. 指紋、血液、鞋印要帶回車上用設備分析；手機等硬證物要「裝袋」帶回車上、交給快遞員小吳送實驗室（大型證物更貴），隔幾個動作才回報告。
4. 打開「筆記本 → 鑑識手冊」對照特徵，點數用完（或被分局長催）就「結案推理」：選兇手、行兇方式、兇器、第一現場與最多 3 項關鍵證據，送出後評分（S/A/B/C/D）。

操作：電腦 WASD／方向鍵移動、E 互動、點地板自動走；手機拖曳畫面當搖桿、點物件互動。

## 程序生成案件（每局都不一樣）
- 每局隨機：兇手（7 名關係人中抽 4 位上場）、行兇方式、兇器、第一現場、死亡時間。
- **鑑識手冊**：每種手法固定 3 個鑑識特徵——
  - 鈍器重擊：凹陷傷／大量血跡／兇器血跡反應
  - 刺殺：銳器傷／大量血跡／兇器血跡反應
  - 勒斃：勒痕／指甲縫皮屑／屍斑不符（移屍）
  - 下毒：無外傷／毒物反應／杯緣殘留
  - 偽裝意外：凹陷傷／屍斑不符（移屍）／拖地痕（在客廳或廚房行兇，再把屍體搬到書房）
- **嫌犯特徵表**：鞋號、血型、慣用手、指紋、不在場說法；生成時保證兇手的可觀察特徵與每位無辜者都不同。
- **誘餌**（依難度 1–3 個）：無辜者的舊指紋、別間房的舊血跡、兇手栽贓的物品（送驗會發現是事後放的）、指向無辜者的第二份動機文件。
- 難度同時決定：全隊點數（簡單 32／普通 28／困難 24）、實驗室延遲、誘餌數、各種壓力的頻率。
- 每個案件都保證可破：測試對 300 個種子 × 3 種難度檢查「完整資訊下答案唯一」與「最省路線在點數內、還有 4 點以上餘裕」。

## 壓力系統
- **證據會衰退**：時間越久肝溫推算越不準、指甲縫血跡氧化（車上驗不出血型，只能送實驗室驗 DNA）、下雨後後院鞋印被沖掉。
- **兇手混在關係人裡**：會趁沒人注意溜進去擦兇器指紋、清手機；被你發現 2 條指向他的線索後會**逃跑**（80 距離內有隊員就能攔下，逃走會扣 10 分）；也會威脅落單的隊員（扣 1 點）。無辜的人也會好奇亂晃，所以「有人溜進去」不等於他就是兇手。
- **分局長（鄭督察）的里程碑**：時限內完成「傷口＋死亡時間」「至少一次車上分析」可加點；失敗會扣點或讓實驗室變慢；最終時限到了強制結案。
- **菜鳥員警小林**：會闖進封鎖線走向某個證物，沒人攔就會汙染指紋、碰壞某人的工具或浪費點數。靠近他就能攔下。
- **沒有內鬼／叛徒模式**：所有玩家都是同一隊。

## 行動點數（AP）的設計決定：每人各自一池，總量固定
全隊總點數由難度決定，平均分給每位玩家（例如普通 28 點：單人 28、2 人各 14、4 人各 7）。
理由：①不管幾個人玩，案件難度一致；②每個人管理自己的點數，不會有人一口氣把全隊點數花光、其他人只能看；③自然鼓勵分工（一人去後院採鞋印、一人回車上分析）。有人離線時，他剩下的點數會平均分給還在的人。

## 換美術圖
所有圖片目前都是程式畫的**佔位圖**。把同檔名的 PNG 放進 `docs/assets/` 覆蓋即可（尺寸見清單），不用改程式。
- 生圖提示詞：[`ART_PROMPTS.md`](ART_PROMPTS.md)（共 84 張，含統一風格描述、英文 prompt、中文說明、尺寸、是否透明背景）。
- `npm run assets` 會重畫佔位圖，但**只覆蓋仍是佔位圖的檔案**（你換上的圖不會被蓋掉）；`npm run prompts` 只重寫 ART_PROMPTS.md。

## 開發與測試
```bash
npm install
npm start            # http://localhost:3000（同時提供網頁與 /ws）
npm test             # 規則、點數、案件可解性、伺服器多人同步（2+ 個 ws 用戶端）
NODE_PATH=<playwright 的 node_modules> node test/e2e.js http://localhost:3000/   # 瀏覽器實際玩一局（桌機＋iPhone 13）
```
網頁會自動判斷伺服器：在 localhost／Render 上用同一個網址；在 GitHub Pages 上預設連 `wss://forensic-scene-online.onrender.com/ws`，可用 `?server=wss://你的網址/ws` 覆蓋。

### 伺服器環境變數（全部可選）
| 變數 | 說明 |
|---|---|
| `PORT` | 埠號（Render 自動設定） |
| `CF_TURN_KEY_ID` + `CF_TURN_API_TOKEN` | Cloudflare Realtime TURN（語音穿透） |
| `METERED_DOMAIN` + `METERED_SECRET_KEY`／`METERED_API_KEY` | Metered TURN |
| `TURN_URLS` + `TURN_SECRET` | 自架 coturn（HMAC 短效帳密） |
| `TURN_URLS` + `TURN_USERNAME` + `TURN_CREDENTIAL` | 固定帳密 TURN |
| `TURN_DEFAULT=off` | 不用 Open Relay 公開中繼（只剩 STUN） |
| `PRESSURE=off` | 關閉壓力系統（測試用） |
| `MAX_ROOMS`、`ROOM_IDLE_MS`、`LIM_*` | 房間上限、閒置清理、頻率限制 |

## 部署多人伺服器（Render 免費方案）
1. 登入 <https://dashboard.render.com> → **New → Blueprint**。
2. 連接 GitHub，選 `190Boy/forensic-scene-online` → Render 會讀到 `render.yaml`（plan: free）→ **Apply**。
3. 等部署完成，打開 `https://<服務名稱>.onrender.com/healthz` 看到 `ok`。
4. 如果服務網址不是 `forensic-scene-online.onrender.com`，GitHub Pages 版請加 `?server=wss://<你的網址>/ws`，或改 `docs/app.js` 的 `DEFAULT_SERVER`。

免費方案閒置會休眠，第一個人連線要等 30–60 秒冷啟動；本專案刻意**不做**任何 keep-alive／定時 ping。

## 技術
- `docs/casegen.js` 案件生成（固定種子 → 相同案件）｜`docs/engine.js` 規則與壓力系統（瀏覽器與伺服器共用，伺服器權威）｜`docs/assets.js` 美術清單與佔位圖｜`docs/app.js` 畫面、輸入、聊天、語音（WebRTC mesh，信令走 /ws）
- `server.js` 只依賴 `ws`：房號、token 重連、不可用名字搶位、頻率限制、/ice、/healthz。
