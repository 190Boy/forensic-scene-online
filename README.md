# 🔍 鑑識現場 Forensic Scene Online

《Phasmophobia》式的安靜合作鑑識遊戲：1–4 名鑑識人員開著**行動鑑識車**抵達雨夜的命案別墅，關燈噴魯米諾、採指紋、送實驗室，慢慢拼出**行兇方式、兇器、第一現場與兇手**，最後提交推理報告評分。斜 45° 俯視（類 Among Us）2D，桌機與 iPhone 都能玩。

- 單人（離線也能玩）：<https://190boy.github.io/forensic-scene-online/>（第一次玩先按 **🎓 新手教學**）
- 多人連線伺服器：<https://forensic-scene-online.onrender.com>（Render 免費方案，閒置後第一次連線要等 30～60 秒喚醒）

## v18：多人各自推理、一起開獎
- **每個人寫自己的推理報告**：`st.drafts[pid]`／`st.submitted[pid]`／`st.results[pid]`。選兇手、手法、兇器、現場、關鍵證據只改自己的草稿；推理中伺服器只把**自己的草稿**傳給你（看不到隊友答案），但大家都看得到誰「✅ 已送出／⏳ 思考中」。
- **每個人都能送出**（不再只有房主）；全員送出 → 自動開獎，各自計分、各自評價。房主可以按 **⏭️ 立刻開獎**（沒送出的人用目前草稿計分，空白欄位 0 分）。推理中有人離隊或斷線太久 → 剩下的人都送出了就自動開獎，房間不會卡住。
- **結案報告**：上面是你的個人成績；多人時下面有 **🏆 全員推理成績比較**（依分數排序、你／🏆 最高分標籤、兇手／手法／兇器／現場 ✔✖，還看得到每個人指認的兇手）。關掉後按「📁 結案報告」重看；再玩一局全部重置。單人／教學跟以前一樣（送出立刻開獎，`st.draft`／`st.result` 照舊）。

## 怎麼玩
1. 首頁輸入名字、選隊員與難度 → 「新手教學」「單人調查」或「建立房間」（4 位數房號，把邀請連結傳給隊友）。
2. 在鑑識車選最多 3 件工具（**隨時免費更換**），走進封鎖線，靠近發亮的「!」物件按按鈕採證。**工具都可以無限使用**，只有魯米諾一瓶 3 次（工具格右下角顯示剩幾次），回車上免費補充。
3. 每次用工具都會跳出**結果卡**：發現什麼、記在筆記本哪裡（新證據有「新」標記），畫面上也會浮出文字。左上角有**目前目標**提示、**案情進度 %**、**待處理**（要拿回車上分析的樣本、等實驗室報告的倒數）。
4. 指紋、血液、鞋印帶回車上用設備分析（免費）；手機等硬證物「裝袋」交給快遞員小吳送實驗室，約 40～70 秒後報告回來、再跳一次結果卡。
5. 線索夠了**隨時可以結案**：選兇手、行兇方式、兇器、第一現場與最多 3 項關鍵證據，送出後評分。

操作：
- **電腦**：WASD／方向鍵移動（或點地板自動走）。靠近物件時，物件旁邊會出現一個半透明的小清單：
  - **數字鍵 1–5**＝對這個物件用工具（例如屍體：`[1] 近拍傷口 [2] 檢查屍斑 [3] 量測肝溫…`，編號依清單順序，已完成的會收起來）；
  - **E**（或空白鍵）＝不需要工具的互動：裝袋帶走、開／關燈、記錄螢光位置、打開鑑識車、找關係人問話、請小吳取件；
  - 一個物件若有多個非工具互動，第一個是 E，其餘接在數字後面；滑鼠點清單也可以。**N** 打開筆記本。
- **手機**：拖曳畫面當搖桿、點物件；靠近時下方出現一排可左右滑動的小按鈕。
- 地上的**黃色三角錐**是「證物標記」：表示那裡的魯米諾螢光已經記錄成證據，數字＝筆記本裡的證據編號；走近或滑鼠移上去會顯示「證物標記 N：…」。

## 資源：沒有個人行動點數
- 大部分工具無限用；魯米諾是消耗品（3 次／瓶，回車上補充）。
- 唯一要省的是**全隊共用的實驗室額度**（簡單 14／普通 11／困難 9）：送實驗室、請小吳到現場取件、樣本送 DNA 都要花。
- 結束條件：全隊決定結案，或**分局長的耐心**歸零被強制結案。
- 分數＝答對多少（兇手、手法、兇器、第一現場、關鍵證據）＋結案速度獎勵（耐心剩越多越高，最多 +10）＋省下的實驗室額度（最多 +5）。獎勵只在基本分 50 以上才算，避免亂猜早交。

## 電燈開關與魯米諾
- 房間平常都是亮的，客廳、書房、廚房門邊各有一個**電燈開關**。
- 魯米諾的藍色螢光只有在**那間房的燈關掉時**才看得到；關燈後會用手電筒照向面對的方向。
- 看到螢光後按「記錄螢光位置」才算證據，會留下黃色標示牌，開燈後還在。
- 多人：一人關燈、一人噴灑記錄；單人自己來。每間房的燈由伺服器同步。

## 封鎖線裡的人
- **員警**（依難度 3～5 位）在封鎖線內站崗、巡邏。其中一位（困難兩位）其實是**菜鳥**：偶爾會走向某個證物，頭上冒出 ⚠️、跳出提示和輕柔的提示音。走過去碰他，他就會回崗位；沒攔住會汙染指紋、碰壞工具或打翻魯米諾。一般員警無害。
- **分局長（鄭督察）**：像 Phasmophobia 的鬼一樣偶爾走進封鎖線，頭上的**泡泡**用圖示＋文字寫著要求——某份報告（傷口照片／死亡時間／指紋比對／血液報告／實驗室報告）或「案情進度要到 N%」。做到後去碰他：實驗室額度 +2、耐心回升，他就離開。
  - 不理他：耐心掉得更快（等待時 ×3、走掉再 −12），而且輪流發生「之後送實驗室每次多花 1 點」或「一位隊員被叫去寫報告 1 分鐘」（單人改為額度 −2）。
- **兇手混在關係人裡**（低調）：偶爾溜進去擦兇器指紋或清手機。被發現 2 條指向他的線索後會想溜走：
  - **先有預警**：頭上冒 😰、慢慢往出口挪、畫面上方出現提示列；預警秒數依人數調整（單人 12 秒、2 人 9 秒、3 人以上 6 秒），之後才真的跑。
  - **人少（1～2 人）**：按 **E**（或點提示列的「叫員警攔住他」）請最近的員警去追，員警跑得比他快、會把他攔下；也可以自己走過去碰他。
  - **3 人以上**：維持自己去攔（走到他旁邊碰他）。
  - 完全不理就會讓他跑掉，結案扣 10 分。無辜的人也會好奇亂晃。
- 分局長與菜鳥的插曲**很少、而且不會重疊**（每段之間至少安靜 75 秒）。**沒有內鬼／叛徒模式**，所有玩家都是同一隊。

## 氣氛
雨聲、冰箱低鳴（靠近廚房會比較大聲）、遠處狗叫、偶爾地板嘎吱聲，全部用 WebAudio 即時合成（選單可關）。靠近證物或照到螢光時有輕微提示音；案發房間有一點色調；提示都很柔和，沒有大型倒數計時，時間用「22:40 → 天亮」的夜晚時鐘表示。

## 鑑識小遊戲（v9）：採證要靠手感
每次對物品用工具、或檢查屍體，都會打開一個 30–50 秒的小遊戲（滑鼠＋鍵盤、iPhone 觸控都能玩；`Esc`／「放下工具」可取消）。玩得越仔細，**樣本品質**越好（好 ≥70%、普通 ≥40%、其餘為差）。結果卡和筆記本只顯示「樣本品質：好／普通／差」，**不會**告訴你結果有沒有失真。

| 小遊戲 | 用在 | 操作 | 品質怎麼影響證據 |
|---|---|---|---|
| 📷 拍照 | 屍體：近拍傷口、屍斑、雙手 | 移動取景框，停穩對焦（框變綠）再拍；6 張底片 | 好＝完整（含慣用手）；普通＝部分（看不出慣用手）；差＝照片模糊、沒有資訊 |
| 🔦 魯米諾記錄 | 地毯、地板、兇器、拖把（關燈後） | 慢慢移動紫外燈，藍光浮現後點一下標記，掃完按完成 | 差＝「沒看到螢光」（真正的第一現場可能被誤排除）；重做要再噴一次魯米諾 |
| 🖌️ 刷指紋 | 兇器、杯子、領帶… | 按住拖曳刷粉，紋路出現就換地方，刷太多會糊 | 好＝完整指紋；普通＝半枚（要送實驗室強化）；差＝糊掉；重做最多普通 |
| 🌡️ 肝溫 | 屍體 | 按住讓指針待在綠色區間，再依暖氣／窗戶選修正方向 | 普通＝死亡時間範圍變寬；差＝範圍偏移（看起來很正常） |
| 👣 鞋印 | 兇手的鞋印（每局在後院／玄關／廚房／客廳／書房，泥鞋印、灰塵或血鞋印） | 手電筒照路，依序點出同一雙鞋的腳印，避開員警靴印 | 普通＝鞋號範圍；差＝範圍偏掉；重做最多普通 |
| 🧪 棉棒 | 死者血液、指甲縫、關係人身上的血漬 | 按住在虛線內來回輕擦，碰到外面或太用力會污染 | 差＝樣本被污染、驗不出結果 |

- 每一項可以**重做一次**（舊結果作廢）。分數由前端算，伺服器檢查範圍與最短時間後決定品質。
- 做小遊戲的人**站著不動、顧不到四周**（頭上顯示「🔬 分析中」，不算看守現場），菜鳥和兇手要靠隊友注意。
- 筆記本「🧬 比對」頁：現場證據 vs. 關係人的鞋號／血型／慣用手／指紋；「鑑識手冊」可勾「只用可靠的證據推論」。
- 同一件物品每局意思可能不同：例如領帶可能是勒斃工具，也可能塗了箭毒蛙毒素（新手法「接觸性毒物」）；火鉗可能是鈍器也可能是刺器。
- **關係人身上的血漬（v10）**：每局 1–2 位關係人的袖口／衣角／鞋尖／褲管有疑似血漬（人物身上看得到小紅點，靠近會提示）。帶棉棒靠近按「採集…的血漬」→ 回車上離心機看血型（和死者同型＝可疑），或送實驗室驗 DNA（與死者 DNA 吻合＝直接證據；「不是死者的血：本人割傷／生肉血水／紅酒漬」＝誘餌）。流血的手法兇手常沾到死者的血；不流血的手法只有誘餌污漬。
- **分局長交差（v10 修正）**：碰到他（半徑和提示列一致）或在提示列按 **E／👔 交差**；做小遊戲殘留的狀態不會再卡住交差。
- e2e 用 `?mgfast` 可縮短小遊戲時間；`__fs.mgFinish(分數)` 可直接結束。

## 新手教學
首頁「🎓 新手教學」：固定的小案件（種子 7），25 個步驟，用箭頭和高亮一步一步帶過每個系統：員警報告與調度、觀察／周旋關係人、兩組工具共 6 種、關燈與魯米諾、車上分析、裝袋送實驗室、分局長交差、攔菜鳥、筆記本與鑑識手冊、結案推理。不會失敗，亂序做也會自動往前跳，約 4 分鐘（詳見上面 v16）。

## 程序生成案件（每局都不一樣）
- 每局隨機：兇手（7 名關係人中抽 4 位上場）、行兇方式、兇器、第一現場、死亡時間、哪位員警是菜鳥。
- **鑑識手冊**：每種手法固定 3 個鑑識特徵——
  - 鈍器重擊：凹陷傷／大量血跡／兇器血跡反應
  - 刺殺：銳器傷／大量血跡／兇器血跡反應
  - 勒斃：勒痕／指甲縫皮屑／屍斑不符（移屍）
  - 下毒：無外傷／毒物反應／杯緣殘留
  - 偽裝意外：凹陷傷／屍斑不符（移屍）／拖地痕（在客廳或廚房行兇，再把屍體搬到書房）
- **嫌犯特徵表**：鞋號、血型、慣用手、指紋、不在場說法；生成時保證兇手的可觀察特徵與每位無辜者都不同。
- **誘餌**（依難度 1–3 個）：無辜者的舊指紋、別間房的舊血跡、兇手栽贓的物品、指向無辜者的第二份動機文件。
- **證據會慢慢衰退**（比 v1 溫和很多）：肝溫推算越來越不準、指甲縫血跡氧化、下雨後後院的鞋印被沖掉（鞋印在屋裡就不會）。
- 每個案件都保證可破：測試對 300 個種子 × 3 種難度檢查「完整資訊下答案唯一」與「最省路線花的實驗室額度還留 2 點以上餘裕」。

## 換美術圖
所有圖片目前都是程式畫的**佔位圖**。把同檔名的 PNG 放進 `docs/assets/` 覆蓋即可（尺寸見清單），不用改程式。
- 生圖提示詞：[`ART_PROMPTS.md`](ART_PROMPTS.md)（共 98 張，含統一風格描述、英文 prompt、中文說明、尺寸、是否透明背景）。v2 新增 5 位員警、教學導師頭像、6 個分局長要求圖示、菜鳥警示、教學箭頭、電燈開關。
- **比例尺（v8）**：成年角色身高 H = 112 世界單位，牆高 112。3/4 俯視下家具比真實比例放大約 1.4 倍（沙發 1.8 H、書櫃 1.5 H、茶几 1.1 H、書桌／壁爐 1.6 H、門 1.3 H），小證物放大約 1.5 倍以便辨認，屍體維持約 1.05 H。尺寸寫在 `docs/casegen.js` 的 `SIZES`；換圖時圖檔會裁到內容邊界，顯示尺寸由 `SIZES` 決定；重生狀態見 [`ART_REGEN.md`](ART_REGEN.md)。
- `npm run assets` 會重畫佔位圖，但**只覆蓋仍是佔位圖的檔案**（你換上的圖不會被蓋掉）；`npm run prompts` 只重寫 ART_PROMPTS.md。

## 開發與測試
```bash
npm install
npm start            # http://localhost:3000（同時提供網頁與 /ws）
npm test             # 規則、實驗室額度、案件可解性、員警／分局長、電燈、伺服器多人同步（2+ 個 ws 用戶端）
NODE_PATH=<playwright 的 node_modules> node test/e2e.js http://localhost:3000/   # 瀏覽器實際跑新手教學＋一局＋連線開關燈（桌機 1280＋iPhone 13）
```
網頁會自動判斷伺服器：在 localhost／Render 上用同一個網址；在 GitHub Pages 上預設連 `wss://forensic-scene-online.onrender.com/ws`，可用 `?server=wss://你的網址/ws` 覆蓋。

### 伺服器環境變數（全部可選）
| 變數 | 說明 |
|---|---|
| `PORT` | 埠號（Render 自動設定） |
| `CF_TURN_KEY_ID` + `CF_TURN_API_TOKEN` | Cloudflare Realtime TURN（語音穿透） |
| `METERED_DOMAIN` + `METERED_SECRET_KEY`／`METERED_API_KEY` | Metered TURN |
| `TURN_URLS` + `TURN_SECRET` | 自架 coturn（HMAC 短效帳密） |
| `TURN_URLS` + `TURN_USERNAME` + `TURN_CREDENTIAL` | 固定帳密 TURN |
| `TURN_DEFAULT=off` | 不用 Open Relay 公開中繼（只剩 STUN） |
| `PRESSURE=off` | 關閉壓力系統（測試用） |
| `MAX_ROOMS`、`ROOM_IDLE_MS`、`LIM_*` | 房間上限、閒置清理、頻率限制 |

## 部署多人伺服器（Render 免費方案）
1. 登入 <https://dashboard.render.com> → **New → Blueprint**。
2. 連接 GitHub，選 `190Boy/forensic-scene-online` → Render 會讀到 `render.yaml`（plan: free）→ **Apply**。
3. 等部署完成，打開 `https://<服務名稱>.onrender.com/healthz` 看到 `ok`。
4. 如果服務網址不是 `forensic-scene-online.onrender.com`，GitHub Pages 版請加 `?server=wss://<你的網址>/ws`，或改 `docs/app.js` 的 `DEFAULT_SERVER`。

免費方案閒置會休眠，第一個人連線要等 30–60 秒冷啟動；本專案刻意**不做**任何 keep-alive／定時 ping。

## 技術
- `docs/casegen.js` 案件生成（固定種子 → 相同案件）｜`docs/engine.js` 規則與壓力系統（瀏覽器與伺服器共用，伺服器權威）｜`docs/assets.js` 美術清單與佔位圖｜`docs/app.js` 畫面、輸入、聊天、語音（WebRTC mesh，信令走 /ws）
- `server.js` 只依賴 `ws`：房號、token 重連、不可用名字搶位、頻率限制、/ice、/healthz。
